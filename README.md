# JDX-wallpaper 🚘

JDX-wallpaper — живые обои с автомобилями и динамическими визуальными эффектами для Windows.

В стандартную версию входят 6 автомобильных обоев. Коллекция будет постепенно пополняться новыми изображениями.

Проект предназначен для [Lively Wallpaper](https://livelywallpaper.net/).

## 🚀 Установка

Устанавливать файлы вручную не нужно — просто добавь проект в Lively Wallpaper по ссылке.

1. Открой Lively Wallpaper.
2. Нажми кнопку «+».
3. Выбери пункт «Введите URL».
4. Вставь ссылку на проект:

   https://fleen-5177.github.io/JDX-wallpaper

5. Подтверди добавление и дождись загрузки обоев.

Готово! После добавления проект появится в библиотеке Lively Wallpaper.

При обновлении сайта новые версии и изображения будут доступны по этой ссылке.

## 🧩 Редактирование и собственные обои

Хочешь изменить проект или добавить собственные изображения?

Для этого необходимо скачать исходный проект с GitHub.

### 1. Скачай проект

Открой репозиторий:

https://github.com/fleen-5177/JDX-wallpaper

Затем нажми Code → Download ZIP и распакуй архив.

### 2. Добавь собственное изображение

Помести изображение в папку проекта, рядом с index.html и script.js.

### 3. Добавь изображение в галерею

Открой script.js и найди массив WALLPAPERS.

Добавь новый объект с параметрами изображения:

{
    id: "my-car",
    name: "My Car",
    image: "my-car.jpg",
    thumbnail: "my-car.jpg"
}

| Параметр |    Описание                          |
|----------|--------------------------------------|
| id       | Уникальный идентификатор изображения |
| name     | Название в галерее                   |
| image    | Путь к основному изображению         |
| thumbnail| Путь к миниатюре                     |

Важно:
- Каждый id должен быть уникальным.
- Имя файла должно совпадать с указанным в коде.
- Между объектами массива необходимо ставить запятые.
- После изменений перезагрузи локальную копию проекта в Lively Wallpaper.

Изменения локальной копии не затрагивают оригинальный проект и не становятся доступными другим пользователям автоматически.

## ⚙️ Настройки

Открой панель настроек с помощью кнопки с шестерёнкой.

Доступны следующие параметры:

- Интенсивность снегопада.
- Размер снежинок.
- Прозрачность снега.
- Скорость метели.
- Сила ветра.
- Параллакс.
- Туман.
- Пульсация свечения.

Настройки сохраняются автоматически.
